    Error Code Diagnostics in Burlington, VT

    Codes like Rinnai LC, Navien E003 or Noritz 90 tell us a lot about what is going wrong. We read the code history, test flame rods, flow sensors and igniters and check gas pressure at the inlet.     Condensing Unit and Neutralizer Service in Burlington

    High-efficiency condensing tankless heaters produce acidic condensate that must be neutralized before it goes down a drain. We inspect the condensate trap, line and neutralizer cartridge and replace the media when it is spent. A clogged trap can cause shutdowns or water leaking inside the cabinet. We also check that the line is protected where it runs outdoors.

    Isolation Valve Kit Installation in Burlington, VT
