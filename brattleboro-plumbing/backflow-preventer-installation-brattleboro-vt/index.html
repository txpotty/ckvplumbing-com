    Reduced Pressure Zone (RPZ) Assembly Installation in Brattleboro

    Two independent checks and a relief valve make up an RPZ. When pressure between the checks gets too close to supply pressure, the relief opens, dumping water to the floor or a drain so nothing can pass upstream, which is why we never bury one in a pit in Brattleboro. We install Watts and Febco units.

    Double Check Valve Assembly (DCVA) Installation in Brattleboro

    A double check valve assembly, or DCVA, uses two spring-loaded checks in series with four test cocks. It is the usual pick for low-hazard lines such as many fire sprinklers, and because it does not discharge water, it can go in a vault where local rules allow it, sized so it does not rob your system of pressure in Brattleboro. Test cocks stay reachable.

    Reduced Pressure Zone (RPZ) Device Installation in Brattleboro, VT

    High-hazard connections in Brattleboro, VT call for a reduced pressure zone assembly. Think chemical injection or medical equipment, where a backflow event could put something toxic in the supply, so the RPZ adds a relief valve between two checks that dumps water if either check leaks.
