    Rough-In Plumbing for Urinals in Brattleboro, VT

    Rough-in decides whether the finish goes smoothly. We set the carrier, run a 2 inch waste line to the outlet height on the spec sheet, stub the 3/4 inch supply where the flush valve will land, and tie the vent in before anyone hangs drywall. Inspectors see it open. Then the walls close.

    American Standard and Kohler Urinal Installation in Brattleboro

    American Standard and Kohler make the china we install most. Models like the Washbrook and the Bardon come in versions from 0.125 to 1.0 gallons per flush, and each one needs a flush valve matched to that rating or the bowl will either splash or not rinse clean. Matching is simple with the spec sheet. We order both together.

    Waterless Urinal Upgrades in Brattleboro

    Switching to waterless is mostly a fixture swap. The old flush valve comes off, the supply gets capped behind the wall, and the new waterless bowl goes on the same carrier with its cartridge housing tied into the existing drain. Many jurisdictions want a capped supply kept for later. That allows a future change back.

    Sensor Urinal Installation in Brattleboro, VT

    Sensor valves stop missed flushes and double flushes. We install battery or hardwired units, set the sensing range so the valve does not fire when someone walks past, and turn on a sanitary flush cycle if the restroom sits empty for long stretches. Expect years between battery changes. Hardwired units need an electrician first.

    ADA Urinal Installation in Brattleboro

    Accessible urinals start at the carrier. The carrier gets set for a 17 inch rim, the floor space stays clear, and the flush control stays reachable. Measurements get checked twice. Inspectors measure too.

    Office and Restaurant Urinal Installation in Brattleboro

    Restaurant restrooms see a lot of traffic in short bursts. Busy bars can see hundreds of flushes a night, so we install valves that recover fast and carriers that stay tight. Vandal-resistant valves are available. Night installs keep you open.

    Waterless Urinal Installation in Brattleboro

    Waterless urinals save the most water and need the most discipline. A cartridge or sealing liquid blocks sewer gas while letting urine through, and it must be replaced on schedule. Cleaning staff need a quick lesson. We show them how.
