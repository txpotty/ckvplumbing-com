    Zoeller Sewage Ejector Pump Installation in St. Johnsbury

    Zoeller's sewage line covers home and heavier-duty use, in cast iron with tethered or vertical float switches.     Cost-Effective Sewage Ejector Pump Upgrades in St. Johnsbury, VT

    Upgrading an old ejector can often keep the existing pit. With a sound basin, a new pump, fresh check valve, shutoff and alarm give you most of a new system for far less. Cracked basins get replaced.

    Commercial Sewage Ejector Pump Installation in St. Johnsbury, VT

    Businesses in St. Johnsbury, VT with restrooms, kitchens or break rooms below grade need ejector systems that keep up with heavier, steadier use than a house. A duplex system with an alternating panel is common, so if one pump fails the other keeps things running. Closed restrooms cost business. Each pump can carry the load alone.

    Grinder Pump Installation in St. Johnsbury

    Grinder pumps chop waste into a fine slurry first, which lets them push through small pipe over long distances. They are the right choice when the sewer is far away, uphill or under pressure, like on a pressure sewer system where the pump feeds a shared force main in the street. Grinders run pricier. For a basement bath near the drain, a standard ejector usually works.

    Basement Bathroom Ejector Systems in St. Johnsbury

    Basement bathrooms sit below the building sewer, so every fixture drains to a sealed pit instead of flowing by gravity. We cut the slab, trench the drain lines to the basin, set it, run a two-inch vent up through the house to the roof and pipe the discharge to the building drain with a check valve and shutoff. Then we patch the concrete.

    Ejector Pump Installation Cost Comparison in St. Johnsbury, VT

    Replacing a pump in an existing basin costs the least, often done in a few hours. A new system with a basin, slab excavation, venting through the roof, electrical work and an alarm costs more, but it is the only way to add a bathroom below the sewer line in most homes without a macerating unit. Ask for both numbers.

    Sewage Ejector Pump Basin Installation in St. Johnsbury, VT

    The basin is where the system lives, and a 30-gallon size is common for a single basement bathroom. Bigger basins let the pump run longer, fewer times a day, which is easier on the motor and switch, so we size up when the pit serves a laundry or several fixtures. Lids must be gas-tight.
